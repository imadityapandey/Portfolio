---

## 🌟 Key Features
- **Responsive Layout:** Formatted cleanly across mobile, tablet, and desktop screens.
- **Projects Showcase:** Direct links and summaries for key web development projects.
- **Skills Overview:** Categorized breakdown of tools, programming languages, and technologies.
- **Contact Details:** Quick access to reach out via GitHub and email.

- **Styling:** CSS3 (Flexbox & Responsive Media Queries)

To preview or edit locally:

1. Clone the repository:
   \`\`\`bash

   cd Portfolio
   \`\`\`

2. Open `index.html` in any browser or launch it using VS Code Live Server.
